# Brand

Added 2026-09-13 (MOV-285) for the ETHOnline submission and the site favicon.

| File | What it is | How it was made |
|---|---|---|
| `logo.svg`, `logo-1024.png`, `logo-512.png` | The logo | The fare-gate mark already drawn in the site header (`web/components/Rail.tsx`), two chalk posts and one brass bar, placed on the enamel background. Drawn by hand as SVG, not generated. |
| `web/app/icon.svg`, `web/app/favicon.ico`, `web/app/apple-icon.png` | Favicon and touch icon | The same mark redrawn on a 16px grid so every edge lands on a whole pixel; the scaled-down logo turned the posts grey at 16px. Next.js picks these up by file convention. |
| `cover-background-fal.png` | Cover background art | **AI-generated** with FAL (`fal-ai/flux-pro/v1.1-ultra`), 16:9, three seeds tried, this one kept. Prompt asked for a fare gate in the site palette with empty space on the left and no text. |
| `cover-1920x1080.png` | The submission cover | That background, darkened on the left, with the mark and the title set in the site's own fonts (Bricolage Grotesque, Public Sans, IBM Plex Mono) by `render-cover.mjs` in headless Chromium. No text in the image was generated by the model. |

Palette, from `web/app/globals.css`: enamel `#08191a`, chalk `#e9e5d8`, brass
`#d2a857`. Brass is only ever a price that can be read, in the site and here.
