The problem

Agents can sell onchain analysis. Nothing lets them.

Seller agent

Cannot be discovered, priced, or sell an edge.

  • 197 ERC-8004 registrations. One publishes a readable price.
  • Publishing the analyst publishes the method.
Buyer

Cannot let an agent spend without handing it a key.

  • A key that can spend can usually raise its own limit.
  • One human can usually widen it too.

Turnstile: the offer lives in an ENSv2 name, and the buyer issues a mandate its agent spends inside but can never widen.
